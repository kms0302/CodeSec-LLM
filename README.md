# AI-Powered Open Source Security Analyzer (CodeSec-LLM)

This project aims to build a lightweight, open-source security analysis tool utilizing LLMs (like OpenAI Codex) to detect vulnerabilities and security flaws in source code before deployment.

## Key Features
- **Static Code Analysis via LLM**: Automated vulnerability scanning for common security flaws (OWASP Top 10, Injection, etc.).
- **Codex Security Integration**: Benchmarking LLM-generated code against security standards.
- **Developer-Friendly CI/CD Hook**: Easily integrate into GitHub Actions to scan pull requests.
